# ADR-004: Framework Frontend – ReactJS

**Fecha:** 25/10/2025
**Estado:** Aprobado
**Autor:** Equipo de Arquitectura – LuxLearn
**Versión:** 1.0

## Contexto
Se requiere una interfaz moderna, responsiva y mantenible.

## Decisión
Adoptar ReactJS para la SPA principal del sistema educativo.

## Consecuencias
- Alta modularidad.
- Reuso de componentes.
- Excelente rendimiento.

## Alternativas evaluadas

| Alternativa | Descripción | Pros | Contras | Razón |
|--------------|--------------|------|----------|--------|
| Vue.js | Framework progresivo | Simple | Menor adopción empresarial | Descartada |
| Angular | Framework completo | Robusto | Más pesado | Descartada |
| React | Biblioteca declarativa | Flexible y rápida | Curva inicial de aprendizaje | Aceptada |
