# ADR-003: Uso de Contenedores + Funciones Serverless

**Estado:** Aceptado  
**Fecha:** 2025-01-xx

## 1. Decisión
Adoptar un modelo híbrido de despliegue:

- **Contenedores Docker** para los servicios principales del backend.  
- **Funciones Serverless (FaaS)** para procesos event-driven:
  - Notificaciones  
  - Webhooks  
  - Reportes  
  - Tareas programadas  

## 2. Beneficio
- Escalabilidad automática.  
- Portabilidad de los contenedores.  
- Bajo costo en tareas event-driven.  
- Mejor separación de responsabilidades.  
- Optimización de recursos en la nube.

## 3. Trade-offs
- Mayor complejidad en DevOps.  
- Requiere monitoreo distribuido.  
- Mayor curva de aprendizaje que una VM tradicional.

## 4. Alternativas Consideradas
- **Despliegue en una única VM:** descartado por baja escalabilidad.  
- **Arquitectura completamente serverless:** descartada por problemas de cold start en APIs principales.
